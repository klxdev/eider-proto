# eider-proto

Protocol Buffers (proto3) for [Eider](https://github.com/klxdev/eider-lang): the wire format as a `std/serial` format, unknown fields preserved, with a `.proto` parser and a generator of Eider types to follow (eider-lang#247). Pure Eider; no capability; depends on nothing.

Work in progress: see CHANGELOG.md.
